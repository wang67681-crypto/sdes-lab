# 用户指南

## 启动

在终端进入项目根目录，执行 `npm start`，打开终端显示的地址（默认 http://127.0.0.1:4173）。运行需要 Node.js 20+。没有需要下载的依赖。不要直接双击 index.html：浏览器对 file:// 的模块和 Worker 有限制。

## 加解密工作台

1. 选择「二进制」，输入恰好 8 位的明文和恰好 10 位的密钥。只接受 `0`、`1`，保留开头的零。
2. 点击「开始加密」，得到 8 位密文以及 Hex / 十进制数值。
3. 点击「回填解密」，使用相同密钥解密刚才的结果。
4. 点击下方 IP、第一轮、交换、第二轮和逆置换节点，观察对应的中间值。
5. 「导出计算报告」生成包含参数、输入输出、子密钥和中间计算值的 JSON。

「载入示例」会填入有效输入并执行。「生成随机密钥」使用浏览器的 crypto.getRandomValues。Ctrl / Command + Enter 执行当前实验。选择「解密」可手动粘贴其他程序生成的密文。

## 字符串扩展

ASCII 模式支持字符编码 0–127，每个字节独立加密。密文字节可能无法打印，界面使用 Hex 作为可复制、可交换的主结果，同时展示原始密文字符。解密时粘贴完整 Hex 字节，允许字节之间有空格和换行。UTF-8 为额外扩展，支持中文与 emoji，不改变底层 8-bit S-DES 算法。

示例 `Hello, S-DES!` 可一键加密后回填解密。空字符串有效，结果为空。奇数个 Hex 字符、非 Hex 字符、错误密钥或无效文本编码会提示错误。错误密钥有时仍会解出合法文本，S-DES 本身不提供完整性校验。

## 密钥破解

输入一个或多个已知明密文对，每个字段都为 8 位二进制。点击「搜索全部密钥」，查看全部匹配候选、开始/结束时间（ISO UTC）、真实累计耗时和已测密钥数量。添加约束要求所有明密文对使用同一个未知密钥。最多 32 对。搜索不在首个匹配时停止。

单对数据常有多个候选。多对数据可收窄集合，但不能保证唯一密钥。相互矛盾的约束返回 0 个候选。点击候选可复制，点击「导出破解记录」保存可复核的数据。

## 封闭测试

固定明文后点击「分析碰撞分布」，遍历 1024 个密钥，显示不同密文数、最大碰撞数和 256 格热力图。将鼠标停在格子上查看具体数量；下方表格按碰撞数量排列。完整密钥列表保存在导出 JSON 中。

「全部明文测试」遍历所有 256 个分组，输出每个明文对应的不同密文数与最大碰撞数。计算在后台 Worker 中进行。不同密钥在一个明文上产生相同密文，不等于它们对所有明文都完全等价。

## 交叉测试

选择「算法标准 & 交叉测试」，点击「导出 256 组向量」，将文件交给其他组按同一标准验证。对方结果使用如下格式后导入：

```json
{"vectors":[{"plain":"11010111","key":"1010000010","cipher":"10001100"}]}
```

也支持直接导入向量数组。文件最多 1 MB，数组为 1–10,000 项。输入将被校验，并展示通过数、不一致数量及前 5 项差异。导入文件不会执行代码。
