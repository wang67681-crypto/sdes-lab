# S-DES 实验室设计

组员：王海丞、杨翔宇、刘焱。需求来源：https://shimo.im/docs/m5kvdlMaKvcENy3X/ ，2026-10-08 核对。

采用无第三方运行依赖的 JavaScript 浏览器 GUI，独立纯函数算法模块，Web Worker 执行穷举与碰撞分析。可静态部署于 GitHub Pages，也可使用 Node 本地启动。深色实验台、薄荷绿重点色、逐轮过程可视化、响应式布局、键盘操作、减少动画偏好。

五关：8 位加解密；Python 独立实现交叉验证与可交换 JSON 向量；ASCII 字节扩展并附加 UTF-8 模式；单个/多个明密文对的完整 1024 密钥搜索、真实时间戳与演示动图；对固定明文枚举全部密钥并对全部明文分析碰撞。

参数以课程文档图片为准，S-box2[1][2]=1。位序从左至右 1 起始；P10 中 0 代表第 10 位。LS-2 在 LS-1 后累计左移 2 位。保留原始参数表、可导出完整计算报告。跨组真实测试由其他小组提供结果后比对，不把独立实现测试伪称为已完成组间测试。
